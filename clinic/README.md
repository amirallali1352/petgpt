# پت‌کلینیک

نسخه اول رابط کاربری سامانه مدیریت کلینیک دامپزشکی بر اساس سند نیازمندی‌های پروژه.

## اجرا

فایل [index.html](index.html) را در مرورگر باز کنید. برای اجرای بهتر در محیط توسعه، می‌توانید پوشه پروژه را با یک وب‌سرور ساده سرو کنید:

```powershell
python -m http.server 5500
```

سپس به آدرس `http://localhost:5500` بروید.

## امکانات نسخه فعلی

- داشبورد مدیریتی کلینیک با آمار مشتریان، حیوانات، نوبت‌ها و درآمد
- پروفایل مستقل برای هر مشتری
- ثبت چند پت برای هر مشتری و نمایش پت‌ها داخل پروفایل او
- ثبت مشتری جدید
- ثبت حیوان جدید و اتصال آن به صاحب حیوان
- حداقل ۲۰ نژاد برای سگ، گربه، خرگوش و پرنده با تغییر خودکار نژاد بر اساس گونه
- تقویم شمسی فارسی برای تاریخ تولد با انتخاب روز، ماه و سال
- محاسبه خودکار سن به‌صورت سال، ماه و روز
- بیش از ۲۰ یادداشت اولیه آماده برای انتخاب و ویرایش
- جستجوی مشتری، حیوان و پرونده
- صفحات پایه نوبت‌دهی، پرونده پزشکی، آزمایشگاه، تصویربرداری، جیره‌سازی، گزارش‌ها و تنظیمات
- ذخیره اطلاعات نمونه در `localStorage`
- پشتیبانی از حالت تاریک و طراحی واکنش‌گرا برای موبایل
- رابط کاربری فارسی و راست‌به‌چپ
- استفاده محلی از قالب رایگان و MIT-licensed قالب AdminLTE 4 RTL در پوشه `vendor/adminlte`
- تکمیل صفحات نوبت‌ها، پرونده پزشکی، آزمایشگاه، تصویربرداری، تغذیه، گزارش‌ها و تنظیمات
- ورود نقش‌محور برای مشتری، دامپزشک و ادمین؛ مشتری فقط پروفایل و پت‌های خودش را می‌بیند

این نسخه، لایه رابط کاربری و نمونه تعاملی محصول است. برای نسخه عملیاتی کلینیک باید در مرحله بعد Backend امن با FastAPI، پایگاه داده PostgreSQL، احراز هویت، نقش‌ها، فایل‌استوریج خصوصی و APIهای پزشکی به آن متصل شود.
